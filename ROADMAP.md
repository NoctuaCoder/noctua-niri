# Noctua-Niri Roadmap: Rumo à Superioridade Absoluta 🚀

Este documento estabelece o plano estratégico de desenvolvimento do **Noctua-Niri**, detalhando os eixos necessários para superar as alternativas tradicionais e consolidar a suíte como a referência definitiva para o compositor Niri.

---

## 🎯 Visão Estratégica de Posicionamento

> **A shell Niri-first com a estética mais premium e o maior nível de personalização visual.**
> * Foco em Niri como cidadão de primeira classe.
> * Estética noturna / celestial / glass com física de molas (*spring physics*).
> * Configuração profunda centralizada sem precisar editar código QML.

---

## 🛠️ Eixos de Evolução e Status Atual

### 1. Personalização Real (Concluído)
- [x] **Configuração Externa (`theme.json`)**: Sistema centralizado para gerenciar cores, opacidades, raios de borda e fontes.
- [x] **Hot-Reload de Temas**: Atualização instantânea da interface ao salvar modificações no arquivo de configuração.
- [ ] **Suporte a Matugen / Material You**: Geração automática de paletas de cores a partir do wallpaper atual.

### 2. Estética e Micro-interações Avançadas (Concluído)
- [x] **Glassmorphism Profundo**: Transparências reativas combinadas com bordas neon e glow sutil.
- [x] **Biblioteca QML Reativa (`NoctuaCard`, `NoctuaButton`)**: Componentes modulares com animações de hover e transições suaves.
- [x] **Animações de Entrada/Saída**: Eixos de *fade* e *scale* fluidos em todos os módulos da shell.

### 3. Completude de Shell (Concluído)
- [x] **NoctuaLauncher Nativo**: Menu de aplicativos com parser Python robusto, cache em memória, navegação por teclado e ícones reais.
- [x] **NoctuaOSD Nativo**: Indicador flutuante em tempo real para controle de áudio e brilho.
- [x] **NoctuaPowerMenu Nativo**: Controles dedicados de sessão para Lock, Logout, Reboot e Shutdown.
- [x] **NoctuaNotifications Nativo 2.0**: Daemon DBus resiliente com auto-dismiss, ícones reais e histórico no Dashboard.
- [x] **Segurança Real (Hybrid Lock)**: Bloqueio de sessão real via swaylock integrado à estética Noctua.
